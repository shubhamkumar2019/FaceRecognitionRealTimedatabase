ABOUT

Our group project is a Face Recognition Attendance System that automates student attendance using facial recognition technology. Built with Python, Flask, and integrated with Firebase Realtime Database, the system captures live video through the user's webcam, detects and recognizes faces using OpenCV and the face_recognition library, and updates attendance records accordingly. The web interface includes a landing page and a recognition page, providing a user-friendly way to monitor attendance in real time. The system ensures accuracy by preventing duplicate entries within a short interval and offers a modern solution to traditional attendance methods.
